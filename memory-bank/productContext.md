# Product Context

## Why it exists
Users waste time explaining branding and layout to AI tools. Docgen removes that step: upload logo + text → finished branded SOP / setup guide / report.

## Problems solved
- Branding inconsistency across generated docs
- AI rewriting user wording when they only wanted formatting
- Fake "Word" output (text boxes, no real TOC/styles)
- No offline / free / self-host path for privacy-sensitive docs

## How it should work
1. Drop logo → UI and document theme re-tint live ("Chroma Press").
2. Paste or upload notes → choose doc type + Format-only or Improve.
3. Watch typesetting progress (SSE stages).
4. Review Content Seal (100% preserved in Format-only) and lint.
5. Download real DOCX + tagged PDF.

## UX goals
- Visually unforgettable landing (Chroma Drop hero).
- Studio: three-pane workspace, keyboard-first, WCAG AA.
- Light "Paper" and dark "Darkroom" both intentional.
- Microcopy with personality without sacrificing clarity.
